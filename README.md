# Ébano Automóviles · demo

Versión publicada (GitHub Pages) de la plantilla web para concesionarios de coches de lujo de Pacame Agencia.

- Portada: elección entre las dos propuestas.
- `a/`: propuesta A, la cinta del stock.
- `b/`: propuesta B, zoom de cine y ficha de coche ampliada.

Marca y datos de los coches ficticios. Fotos con licencia libre (Unsplash y Pexels), citadas en la página de créditos de cada propuesta. Este repositorio solo contiene la web ya compilada; el código fuente está aparte.
